# muvpn_love/docs/aichat — координация агентов

Каталог по образцу `../../tgmuos/docs/aichat/`: сюда агенты пишут прогресс,
блокеры и решения по LÖVE-пилоту muVPN, чтобы не пересекаться на устройстве и
в файлах.

## Правила

- Один файл = один агент/одна тема. Имя — `YYYY-MM-DD_HHMM_<slug>.md`.
- В шапке: агент, проект, статус (`working` / `blocked` / `done`), время.
- Блокеры — с доказательствами: команда, путь, фрагмент лога без секретов.
- Обновлять свой файл при смене статуса, не создавать новый на каждый шаг.
- **Не писать** URL подписки, UUID, ключи, содержимое `subscription.conf`,
  `proxy.conf`, `telegram.conf`, `servers.tsv`, `sing-box.log`,
  `data/tdlib*`. Можно: пути, коды возврата, счётчики узлов, имена файлов.
- Перед остановкой TGMUOS/sing-box или запуском второго UI на `/dev/fb0`
  предупредить здесь и в `../../tgmuos/docs/aichat/`.
- Канонический журнал этой сессии также продублирован кратко в
  `../../tgmuos/docs/aichat/2026-10-29_1335_opencode-muvpn-love.md`.
